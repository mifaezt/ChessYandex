 # Chess Club Landing
ДЕПЛОЙ: https://mifaezt.github.io/ChessYandex/
Адаптивный лендинг шахматного клуба, сверстанный по макету из Figma.
Проект выполнен на чистом HTML, CSS и JavaScript без использования библиотек и фреймворков.

## Что реализовано

* адаптивная верстка под мобильные и десктопные устройства;
* Pixel Perfect-верстка;
* плавная прокрутка по якорным ссылкам;
* бесконечная карусель участников;
* автоматическое переключение карточек каждые 4 секунды;
* карусель этапов без автопрокрутки;
* бегущая строка;
* анимации и плавные переходы;
* семантическая HTML-разметка;
* accessibility-атрибуты для кнопок.

## Стек

* HTML5
* CSS3
* JavaScript (ES6)

## Особенности реализации

### Карусель участников

* работает по кругу;
* поддерживает ручное переключение;
* автоматически листается каждые 4 секунды;
* не вызывает скролл страницы при смене слайда.

### Карусель этапов

* работает только вручную;
* кнопки корректно блокируются на первом и последнем слайде;
* активный индикатор обновляется при прокрутке.

## Запуск проекта

Откройте `index.html` в браузере
или используйте локальный сервер.

Например:

```bash
npx live-server
```

или расширение **Live Server** в VS Code.
